# Releases

Per-change release notes land here, one file per private core merge
(`YYYY-MM-DD-short-name.md`), synced automatically by the mirror
workflow. Each note records what changed and where it deployed —
never how it is implemented.

Format:

```md
# YYYY-MM-DD — Title

- **What:** one-line user-visible change
- **Deployed:** chat.lingadevaru.in
```
