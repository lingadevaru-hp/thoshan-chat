# Features (catalog — no source)

- Canned portfolio answers (projects, experience, skills, contact, links)
- AI search over the site index for open questions
- Voice dictation (hold-to-talk on touch, toggle on desktop)
- Read-aloud replies with adjustable speed
- Conversation history: search, export (markdown), share, clear
- Multilingual portfolio switcher (8 locale sites)
- Landing suggestion chips + follow-up chips after each reply
- Embed mode (`?embed=1`): compact layout for the main site's slide-over
- Page context (`?page=slug`): "About this page" chip in embedded use
- Streak + first-voice coachmarks for engagement

Each item above is implemented in the private core; this file only
catalogs what exists.
